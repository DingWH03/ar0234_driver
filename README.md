# ar0234_driver

## How to use

1. Copy the ar0234.c file to drivers/media/i2c/ar0234.c
2. Add the Makefile code for ar0234 to drivers/media/i2c/Makefile below ar0230.
3. Add the Kconfig code for ar0234 to drivers/media/i2c/Kconfig below ar0230.

## supported platforms

* radxa zero3w(rk3566)
* orangepi5(rk3588s)
